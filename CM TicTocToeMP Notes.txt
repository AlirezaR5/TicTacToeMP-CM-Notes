RPCs
This sections was about RPCs which are basically messages that go from client to server and vise versa.
previously we had problem that when clicked in client, it wouldn't spawn the cross. and that's because only server can spawn and do codes. so we tell it to send this request to server and make him run this piece of code. The way to doing this is very simple. Basically we create a method and we give it the attribute "Rpc" and it takes argument that to send who this method. "[Rpc(SendTo.Server)]" because we want server to be able to run this.
Here's the method:
"[Rpc(SendTo.Server)]
private void SpawnObjectRpc(int x, int y)
{
    Transform spawnedCrossTransform = Instantiate(crossPrefab);
    spawnedCrossTransform.GetComponent<NetworkObject>().Spawn(true);
    spawnedCrossTransform.position = GetGridWorldPosition(x, y);
}"
After that we go and change extention from MonoBehavior to NetworkBehavior otherwise it won't work
And then we must end the name of method which has "Rpc" attribute with "Rpc". For example "SpawnObject" -> "SpawnObjectRpc".
And then we go and add Network Object to GameVisualManager because we need it to be on network and not locally.

we create a cross and a circle with two "you" texts below them representing which player you are which is cross for server and circle for client. server will have its own enabaled and client as well. two arrow representing which player turn is,  and they get disabled and enabled based on turn.
after setting these up, we create an script called PlayerUI and attach it to PlayerUI GameObject. in it we get refrences to these ui elements and in Awake we disable them all.
later we need to enable correct "you" text for host and client. we do it after game starts and for determining when game starts, we make a event in GameManager called OnGameStarted and we invoke it when 2 players are connected(host and client). for finding that out there's a callback event that runs everytime a client connects to server, it is called "NetworkManager.Singleton.OnClientConnectedCallback". we subscribe to this in IsServer part with this method "NetworkManager_OnClientConnectedCallback". and in there with "NetworkManager.Singleton.ConnectedClientsList.Count == 2" we check number of connected clients and if true, we invoke OnGameStarted.
after that we sub to "GameManager.Instance.OnGameStarted" in PlayerUI with "GameManager_OnGameStarted" and in there we do GameManager.Instance.GetLocalPlayerType() and enable respecting texts. 
but there's a problem, OnGameStarted event, only gets invoked in server because we did its tied previous logic in IsServer part. and that causes that "you" only works and get shown and enabled in server. to fix we need this event gets invoked in both server and client. to this we need to make a method with ClientsAndHost RPC. 
"[Rpc(SendTo.ClientsAndHost)]
private void TriggerOnGameStartedRpc()
{
    OnGameStarted?.Invoke(this, EventArgs.Empty);
}"
this method gets executed in both server and clients. and in this if "if (NetworkManager.Singleton.ConnectedClientsList.Count == 2)" we call this method. problem fixed.
